# 🧭 Reto : El Laberinto (Indiana Jones)

## Contexto

El reto de esta semana está basado en un **examen real de la primera evaluación del año 2023** del módulo **Desarrollo Web en Entorno Cliente (DWEC)**.

El ejercicio consiste en desarrollar un **mini juego tipo laberinto**, inspirado en _Indiana Jones_, en el que el jugador debe **recorrer un tablero hasta llegar a la meta en el menor tiempo posible**, evitando obstáculos y siendo perseguido por un **fantasma** que sigue su mismo recorrido.
